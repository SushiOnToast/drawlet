# Drawlet - Annotate, Everywhere
Drawlet is a bookmarklet that you can turn on anywhere to annotate on your screen. 

## Features
- Drawing on screen
- Clearing canvas
- Eraser
- Pen and eraser thickness customisation
- Pen colour customisation
- Undo button (or Ctrl-Z functionality)

## How to Add Drawlet as a Bookmarklet
Create a new bookmark and keep its title as "Drawlet" (or whatever you like) and copy this into the URL box:
